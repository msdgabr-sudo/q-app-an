# CP-008 — New Home Migration Baseline

Status: MIGRATION STARTED — DO NOT DELETE LEGACY HOME UNTIL NEW HOME PASSES GATES

Source UI branch: `feature/home-ui-reference-match`
Target integration branch: `new`
Previous safe checkpoint: `CP-007-ASTRONOMICAL-VERIFICATION-OFFLINE-READY`

## Authoritative design rule
The approved Home is the static `#page-home > #qa-home` markup from the source branch. Unlike external pages such as Falaki and Compass, Home must exist in `index.html` at first paint. `js/home-final.js` is binding/data/navigation only and must never regenerate Home markup.

## Protected scientific territory
Do not modify computational Qibla, GNSS, device heading, astronomical verification Gateway/Session/Store/Bridge/Solver, camera permission/capture, FOV/centroid/gravity/quality gates, ±1° acceptance, or verification record policy.

## Compatibility bridge that MUST survive first transfer
The hidden `hm-*` nodes inside the approved Home remain because existing engine/data writers update them. `home-final.js` mirrors those values to the visible `qa-*` nodes. Do not delete the bridge until an explicit later rewire is independently tested.

## Home actions required
- Digital Compass -> `data-go="compass"`, `data-compass-mode="digital"`
- Astronomical Verification -> `data-go="compass"`, `data-compass-mode="astro"`
- Astronomy -> `night`
- GNSS -> `gnss`
- Serenity -> `serenity`
- Prayer/Adhan -> `prayer`
- Quran -> `quran`
- Azkar -> `azkar`
- Settings -> `settings`

## Migration method
1. Inventory approved Home assets and target copies.
2. Port presentation assets only.
3. Port `home-final.js` and `home-reference-finalizer.js` as presentation bindings, adapting only to target navigation/state contracts if needed.
4. Replace only the legacy `#page-home` body in target `index.html`; never overwrite the whole file.
5. Preserve target Compass/Falaki external hosts and all target engine scripts/pages.
6. Merge Home assets into target Service Worker; never replace Service Worker wholesale.
7. Run protected scientific core checks and Home structural/navigation tests.
8. Device acceptance: new Home first paint, no legacy flash, digital mode opens, astronomical mode opens, live values update.

## STOP CONDITIONS
Stop before commit if: duplicate IDs appear; any engine file changes; QT changes; astronomical result can overwrite computational Qibla; a Home card contains fake/hard-coded scientific output; old Home is regenerated by JS; target external Compass/Falaki hosts disappear; or Service Worker loses engine assets.
